# Project Scope Rules

## Studio / Backend Isolation Mode
- **Scope Restriction**: Only modify and work on the Sanity Studio backend (`/ekonova090`, `/studio`, `studio/*`, `ekonova090.html`, `studio.html`).
- **Protected Frontend**: Keep the frontend website (`/`, `index.html`, `src/views/*`, `src/components/*`, `src/styles/*`, `src/main.js`, `src/utils/*`, etc.) completely untouched and unaffected by any changes requested unless explicitly instructed otherwise by the user.
